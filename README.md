# TravelFlow

Demo produk SaaS white-label untuk operator shuttle dan travel. Demo ini dibuat sebagai bahan presentasi calon customer dan tidak menggunakan aset, merek, atau kode DayTrans.

## Menjalankan demo

Buka `index.html` langsung di browser, atau jalankan server lokal:

```powershell
python -m http.server 8080 --directory travelflow-demo
```

Lalu buka `http://localhost:8080`.

## Alur yang sudah dapat dicoba

1. Pilih kota asal, tujuan, tanggal, dan jumlah penumpang.
2. Tekan **Cari Jadwal**.
3. Pilih salah satu perjalanan.
4. Pilih kursi dan lanjutkan pemesanan.
5. Buka menu **Auto Report** untuk melihat dashboard laporan.

Dokumen rancangan produk tersedia di `BLUEPRINT.md`.
